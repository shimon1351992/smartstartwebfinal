🧠 APP LOGIC LAB

VARIABLES + CONDITIONS + RULES + DECISIONS

🏠 הקורס👨‍🏫 מורה🧑‍🎨 תלמיד

🧠 בונים את מוח האפליקציה — על המסך, בלי קוד

💡 מה עושים עכשיו? לפני ש־Canva Code יכול לבנות התנהגות, אתם צריכים לדעת בדיוק מה צריך לקרות לכל בחירה.

עברו ל־Canva ובנו Decision Tree: START → WEATHER? → STORM/CALM → MISSION? → RESCUE/EXPLORE → RESULT.

דוגמת בדיקה: STORM + RESCUE צריך להגיע לתוצאה שהגדרתם בעץ.

בדקו את כל 4 המסלולים באצבע. אם אותו Input מוביל לתוצאה לא נכונה — מצאתם Bug בתכנון.

🚫 אין JavaScript בשיעור הזה — עדיין לא כותבים JavaScript ולא מפעילים Canva Code. במפגש הבא נהפוך את העץ ל־Spec/Prompt.

🚨 היום לא כותבים קוד עדיין

ממשיכים את אותו Web App. המסכים כבר קיימים. היום בונים את “המוח” שלהם כ־APP LOGIC BLUEPRINT + DECISION TREE.

הנוסחה: VARIABLES → CONDITIONS → RULES → DECISIONS → OUTPUT.

☁️ דוגמת SKYLAND

IF mission = RESCUE AND priority = SAFETY THEN RESCUE PACK

mission ו־priority הם Variables; השוואת הערכים היא Conditions; משפט ה־IF/THEN הוא Rule; ו־RESCUE PACK הוא ה־Decision/Output.

1פותחים את אותו Web App

💡 מה עושים עכשיו? פתחו את APP UI KIT + SCREEN SYSTEM ממפגש 21. היום לא מעצבים מחדש — מוסיפים את ההיגיון שמאחורי המסכים.

2VARIABLES

💡 מה עושים עכשיו? בחרו את פרטי המידע שמשתנים לפי בחירת המשתמש. תנו לכל אחד שם קצר וברור.

3VALUES

💡 מה עושים עכשיו? לכל Variable כתבו אילו ערכים הוא יכול לקבל. שמרו על מספר קטן של אפשרויות כדי שהלוגיקה תהיה ברורה.

4CONDITIONS

💡 מה עושים עכשיו? הפכו את המידע לשאלות שאפשר לענות עליהן כן/לא, למשל mission = RESCUE?

5RULES

💡 מה עושים עכשיו? כתבו כללים בצורה IF ... THEN ... . כלל צריך לחבר תנאי לפעולה או תוצאה.

6DECISION TREE

💡 מה עושים עכשיו? בנו ב־Canva עץ: Input → Question → YES/NO → Question/Result. כל נתיב צריך להגיע לתוצאה.

7TEST CASE 1

💡 מה עושים עכשיו? בחרו סט אחד של Inputs ועברו ידנית על העץ. בכל Condition החליטו YES/NO עד Output.

8TEST CASE 2

💡 מה עושים עכשיו? בדקו צירוף אחר. המטרה היא למצוא Rule חסר או נתיב שמוביל לתוצאה לא נכונה.

9BUG → FIX

💡 מה עושים עכשיו? אם מצאתם בעיה, אל תשנו הכול. תקנו Rule או Branch אחד ואז הריצו שוב את אותו Test Case.

10🏆 BOSS — EDGE CASE

💡 מה עושים עכשיו? נסו צירוף Inputs שלא בדקתם קודם. אם העץ נתקע, מצאתם מקרה קצה שצריך לטפל בו.

11LOGIC EXPLAIN

💡 מה עושים עכשיו? תנו לחבר להסביר את הלוגיקה שלכם בלי עזרה. אם הוא לא יכול להסביר מה נבדק ולמה מתקבלת תוצאה — פשטו.

12 💾 שמירה והמשך

💡 מה עושים עכשיו? שמרו APP LOGIC BLUEPRINT + DECISION TREE. במפגש הבא משתמשים בו כ־Spec לבניית WORKING WEB APP V1.
