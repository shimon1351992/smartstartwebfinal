✨ משימת UI MOTION — גורמים לממשק להרגיש חי

💡 מה עושים עכשיו? אל תחפשו “אנימציה מגניבה”. בחרו קודם פעולה של המשתמש ושאלו איזה שינוי קטן יעזור לו להבין מה קורה.

חשבו כך: TRIGGER → MOTION → FEEDBACK → PURPOSE.

בחרו לפחות 3 רכיבים באתר שלכם. לכל אחד החליטו: מה המשתמש עושה? מה משתנה? מה הוא מבין בעקבות השינוי? לאחר מכן עברו ל־Canva ויישמו את האנימציה/האפקט המתאים מתוך האפשרויות הזמינות.

🚫 לא כותבים CSS ולא JavaScript. אתם מעצבים התנהגות.

בדיקת MOTION: Preview → נסו את האתר → אם התנועה מסיחה, מבלבלת או לא עוזרת להבין פעולה, שנו או הסירו אותה.

🚨 חשוב לפני שמתחילים

לא בונים אתר חדש. ממשיכים את אותו Canva Website One-Page ממפגשים 16–17.

כבר קיים: Hero + Sections + תוכן. היום בונים: Navigation + Buttons/Links + בדיקת משתמש. בסוף: INTERACTIVE WEBSITE V2.

1פותחים את אותו אתר

💡 מה עושים עכשיו? פתחו את Canva Website ממפגש 17. ודאו שאתם רואים Hero וכל ה־Sections. אל תפתחו Website חדש.

2JOURNEY MAP

💡 מה עושים עכשיו? כתבו את הדרך המרכזית שהמבקר צריך לעבור. אלה אזורים בתוך אותו One-Page.

3WHERE AM I?

💡 מה עושים עכשיו? עברו Section אחר Section ובדקו האם המבקר מבין איפה הוא.

4WHERE CAN I GO?

💡 מה עושים עכשיו? החליטו אילו אפשרויות מעבר באמת נחוצות.

5NAVIGATION BUILD

💡 מה עושים עכשיו? חזרו ל־Canva והוסיפו/הגדירו ניווט לפי האפשרויות הזמינות. חברו שמות קצרים ל־Sections כשאפשר.

6BUTTONS + LINKS

💡 מה עושים עכשיו? בחרו Buttons/Links חשובים. תנו לכל אחד שם שמסביר מה יקרה וחברו ליעד המתאים.

7WHAT HAPPENS IF I CLICK?

💡 מה עושים עכשיו? פתחו Preview ולחצו על כל רכיב אינטראקטיבי. השוו בין הציפייה לתוצאה.

8LOST VISITOR TEST

💡 מה עושים עכשיו? תנו לחבר משימה כמו “מצא את המוצר שלי”. אל תסבירו את הדרך; צפו איפה הוא נעצר.

🧪 UX TEST CARD

💡 מה עושים עכשיו? עכשיו בודקים את האתר עם אדם אחר. תנו לו משימה אחת ואל תסבירו איך לבצע אותה. צפו במה שהוא עושה וסמנו את הרגע שבו המסלול נהיה מבלבל.
📱 בדיקת Scroll + Mobile: גללו מה־Hero עד ה־CTA. אם Preview מציע תצוגת Mobile, בצעו בה את אותה משימה. בדקו אם סדר ה־Sections והפעולות עדיין ברורים.

9🏆 NO-TALKING UX TEST

💡 מה עושים עכשיו? בחרו משימה נוספת והיוצר שותק לגמרי. האתר צריך להסביר את עצמו.

10REPAIR + RETEST

💡 מה עושים עכשיו? בחרו בעיית UX אחת, תקנו אותה וחזרו על אותה בדיקה.

11 💾 שמירה והמשך

💡 מה עושים עכשיו? שמרו את INTERACTIVE WEBSITE V2 באותו Canva Website. במפגש הבא בודקים ומשיקים אותו.

🏆 BOSS — PURPOSEFUL MOTION

בחרו Micro-interaction אחד והסבירו במשפט: מה מפעיל אותו → מה משתנה → איזה Feedback המשתמש מקבל → למה זה עוזר. אם אין מטרה ברורה, מפחיתים או מסירים את התנועה.
