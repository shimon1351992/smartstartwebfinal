מה באמת לומדים היום?

יזמות מתחילה לא מ“רעיון מגניב” אלא מאדם עם צורך. התלמיד לומד לזהות USER → PROBLEM → NEED → OPPORTUNITY ולהפריד בין בעיה אמיתית לבין פתרון שכבר קפץ לו לראש.

➡️ הבא: מפגש 27 מייצר פתרונות ובוחר MVP.

🎬 Tutorial למדריך — Problem Finder

  1. הציגו שלושה מצבים יומיומיים קצרים ובקשו: מי המשתמש ומה מפריע לו?
  2. פתחו Canva ובנו USER CARD: מי? מה הוא מנסה לעשות? איפה הוא נתקע?
  3. נסחו Problem בלי פתרון: “ילדים ש___ מתקשים ב___ כאשר___”.
  4. הוסיפו NEED: מה הם באמת צריכים?
  5. הפכו ל־OPPORTUNITY: “איך נוכל לעזור ל___ כדי ש___?”
  6. הדגימו טעות: “צריך לבנות אפליקציה...” והראו שזה פתרון, לא בעיה.
  7. בצעו בדיקת אדם נוסף; לא ממציאים ציטוטי משתמש בעזרת AI.
SKYLAND — דוגמת מדריך: מבקרים חדשים בעולם מתקשים לבחור משימה שמתאימה למזג האוויר ולמטרה שלהם → צורך: דרך פשוטה לקבל משימה מתאימה → Opportunity: איך נוכל לעזור למבקר לבחור משימה במהירות?
