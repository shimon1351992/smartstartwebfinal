🎯 מה באמת לומדים היום?

להפוך נכסים קיימים למערכת זהות עקבית שאפשר לזהות ולשחזר.

המיומנות של היום: Brand Identity System

כלי החשיבה: COLORS → SYMBOL → LOGO/FONT → SLOGAN → BRAND KIT → TEST

איך מתרגלים? באמצעות התוצר הממשי של המפגש בתוך Canva — לא באמצעות Worksheet בלבד.

בסוף המפגש התלמיד יוכל: להראות את התוצר שבנה, להסביר החלטה מרכזית אחת ולתאר מה שיפר בעקבות בדיקה.

🔗 רצף הבנייה — מה קיים ומה בונים היום

📦 מה כבר קיים?

העולם, WORLD KIT, CHARACTER KIT ו־STORY POSTER.

🎨 מה בונים היום בפועל ב־Canva?

WORLD BRAND KIT אמיתי: COLORS + SYMBOL + LOGO + FONT + SLOGAN.

✅ מה חייב להיות בנוי בסוף?

Brand Kit/Brand Board שמור בפרויקט ומייצג את העולם באופן עקבי.

➡️ איך זה נכנס למפגש הבא?

במפגש 6 משתמשים במותג ובנכסים האלה לבניית SOCIAL LAUNCH PACK.

מה מלמדים היום?

זהו מפגש הסיום של יחידה 1. התלמידים לוקחים את העולם, הדמויות והסיפור שכבר בנו ומזקקים מהם זהות מותג עקבית. הם אינם ממציאים מותג מנותק: כל החלטה צריכה לצמוח מה־WORLD KIT, CHARACTER KIT ו־STORY POSTER.

🎯 מטרות + מדד הצלחה

להבין LOGO + COLORS + FONT + SYMBOL + SLOGAN.
לבנות WORLD BRAND KIT ממשי.
לקבל החלטות עיצוביות ולא להסתפק בגרסה הראשונה.
לבדוק, לשפר ולשמור כחומר גלם להשקה ביחידה 2.

הצלחה: התלמיד יכול להסביר כיצד כל רכיב מותג מייצג את העולם, ולהצביע על החלטה אחת ששופרה בעקבות בדיקה.

🧑‍🏫 דוגמה מוכנה — ערכת המותג של SKYLAND

LOGO: המילה SKYLAND בשילוב צורת אי מרחף.

COLORS: כחול + לבן + סגול.

FONT: כתב מודרני, נקי, עגול ועתידני.

SYMBOL: אי מרחף / ענן.

SLOGAN: LIVE ABOVE THE ORDINARY.

למה זה עובד? כל הרכיבים חוזרים לשפה שכבר נבנתה ב־SKYLAND במקום להוסיף זהות חדשה.

👎 גרסה חלשה מוכנה להשוואה

לוגו גותי שחור, צבעי אדום/חום, סמל אש וסלוגן שאינו קשור לעולם השמיים. כל רכיב יכול להיות “יפה”, אבל יחד הם אינם מספרים SKYLAND.

🟢 בדיקת Canva Education + הכנה

🟢 Design, Text, Elements, Shapes, Pages. 🟡 Canva AI / Create an Image לפי הרשאות. 🔄 בנייה ידנית ב־Elements.

פתח מראש את SKYLAND ואת תוצרי מפגש 4; הכן WORLD BRAND KIT מלא + גרסה חלשה; בדוק חשבון תלמיד; הכן fallback, טיימר, Boss ומשוב.

הכשרת מדריך: Canva Design School ו־AI in the Classroom כפי שמופיע במדריך המקור.

🎬 פתיחת WOW + המשימה

הצג SKYLAND Brand Kit ואת הגרסה החלשה. שאל: “אם הייתי מסתיר את השם SKYLAND, איזו מהגרסאות עדיין מרגישה כמו העולם שבנינו?”

כתוב: LOGO + COLORS + FONT + SYMBOL + SLOGAN.

Mission: “לבנות WORLD BRAND KIT שמישהו אחר יכול לזהות כשייך לעולם שלכם, לבדוק אותו ולשפר לפחות החלטה אחת.”

🧭 הדרכה מעשית למדריך — בונים מול הכיתה

מטרת ההדגמה: המדריך בונה חלק אמיתי מהתוצר מול התלמידים. זהו scaffolding הוראתי שמיישם את עקרונות המפגש; אין צורך שהתלמידים יעתיקו את SKYLAND.

  1. פתחו את נכסי העולם, הדמויות וה־STORY POSTER.
  2. חלצו מהם COLORS שחוזרים כבר בעבודה.
  3. בנו SYMBOL פשוט ואז LOGO + FONT ב־Canva.
  4. כתבו SLOGAN קצר שמתחבר לעולם.
  5. רכזו הכול על WORLD BRAND KIT/Brand Board אחד.
  6. טעות מכוונת: החליפו פונט/צבע לרכיב אחד כך שלא יתאים. שאלו מה שבר את הזהות.
  7. בצעו BRAND TEST ושפרו רכיב אחד.
  8. בסיום: Brand Board עם COLORS + SYMBOL + LOGO + FONT + SLOGAN.

🖥️ הדגמה צעד־אחר־צעד

  1. פתח את SKYLAND המתמשך ואת STORY POSTER.
  2. סמן 3–5 רמזים חזותיים שכבר קיימים.
  3. התחל ב־SYMBOL: אי מרחף/ענן.
  4. בנה LOGO פשוט סביב שם העולם והסמל.
  5. בחר COLORS שכבר שייכים לעולם.
  6. בחר FONT שתומך באופי ולא נלחם בו.
  7. נסח SLOGAN קצר: LIVE ABOVE THE ORDINARY.
  8. אחד הכל ל־Brand Board.
  9. צור בכוונה רכיב שלא מתאים, בקש לזהות, ושנה דבר אחד בלבד.

START → DECISION → TEST → CHANGE.

🛠️ תכנון → בנייה → בדיקה → שיפור

Plan: לפני Canva, כותבים מה העולם צריך לשדר ובוחרים רמזים מתוצרים קודמים. Build: בונים Logo/Symbol, Colors, Font, Slogan. Check: חבר רואה את ה־Brand Board בלי הסבר ומספר מה הוא חושב שהעולם מרגיש. Improve: שינוי אחד ואז בדיקה חוזרת.

🏆 אתגר הבוס + גלריית היחידה

Boss — BRAND RECOGNITION: הסתירו את שם העולם. האם חבר עדיין יכול לחבר את ה־Brand Board לעולם לפי צבע, סמל ושפה?

Unit Gallery: מציגים WORLD CONCEPT → WORLD KIT → CHARACTER KIT → STORY POSTER → WORLD BRAND KIT. המשוב עוסק בזהות, בהירות, עקביות ושיפור — לא “מי הכי יפה”.

Super Boss: הסר רכיב מותג אחד. האם הזהות עדיין עובדת? הסבר אם היה Must Have או Nice to Have.

🛟 ערכת הצלה למדריך

אין רעיון ללוגו? התחל בשם העולם + סמל אחד מהעולם.
יותר מדי צבעים? חזור ל־3 צבעים מובילים שכבר קיימים.
סלוגן ארוך? מסר אחד, קצר וזכיר.
הכול נראה מנותק? חזור לתוצרי 1–4 וחפש חזרות.
AI חסום? 🔄 Text + Shapes + Elements.
מאחרים? קצץ וריאציות; שמור Test + Save + Next.
