🏠 הקורס👨‍🏫 מצב מורה🧑‍🎨 מצב תלמיד

🎯 מה באמת לומדים היום?

לדחוס סיפור לרגע חזותי אחד שהצופה יכול להבין במהירות.

המיומנות של היום: Visual Storytelling

כלי החשיבה: HERO → WANTS → PROBLEM → MISSION → POSTER → 5-SECOND TEST

איך מתרגלים? באמצעות התוצר הממשי של המפגש בתוך Canva — לא באמצעות Worksheet בלבד.

בסוף המפגש התלמיד יוכל: להראות את התוצר שבנה, להסביר החלטה מרכזית אחת ולתאר מה שיפר בעקבות בדיקה.

🔗 רצף הבנייה — מה קיים ומה בונים היום

📦 מה כבר קיים?

CHARACTER KIT ובו HERO, FRIEND ו־RIVAL.

🎨 מה בונים היום בפועל ב־Canva?

STORY POSTER אמיתי ב־Canva מתוך HERO → WANTS → PROBLEM → MISSION.

✅ מה חייב להיות בנוי בסוף?

פוסטר אחד בנוי, קריא ועובר 5-SECOND TEST.

➡️ איך זה נכנס למפגש הבא?

במפגש 5 הסיפור, הדמות והעולם נכנסים ל־WORLD BRAND KIT.

מה מלמדים היום?

פותחים את CHARACTER KIT ממפגש 3 ולא מתחילים מאפס. התלמידים הופכים דמות לעוגן של סיפור קצר וברור באמצעות HERO → WANTS → PROBLEM → MISSION, ואז מעצבים STORY POSTER בתוך אותו פרויקט MY WORLD.

🎯 מטרות + הצלחה

להבין וליישם HERO → WANTS → PROBLEM → MISSION.
לבנות STORY POSTER ממשי.
לקבל החלטות סיפוריות ועיצוביות ולא לקבל גרסה ראשונה.
לבדוק עם אדם נוסף, לשפר ולשמור למפגש 5.

הצלחה = הצופה יכול לזהות מי הגיבור, מה הוא רוצה, מה הבעיה ומה המשימה — גם בלי הסבר ארוך של היוצר.

🧑‍🏫 דוגמה מוכנה — SKYLAND

HERO: Cloud Leo, הממציא הצעיר.

WANTS: לשמור על SKYLAND ועל האנשים שחיים באיים.

PROBLEM: Crystal Gravity נעלם והאיים מתחילים לאבד יציבות ועלולים ליפול.

MISSION: ליאו יוצא למצוא את Crystal Gravity לפני שהאיים קורסים.

STORY POSTER: ליאו בחזית, אי מרחף שנוטה ברקע, מקום ריק/זוהר שבו היה הקריסטל, כותרת קצרה ומשפט משימה אחד.

👎 גרסה חלשה מוכנה

פוסטר עמוס בשלוש עלילות, אין גיבור ברור, הבעיה מופיעה רק בטקסט קטן והעיצוב אינו משתמש בנכסי SKYLAND. שאל: “מה הסיפור במשפט אחד?”

🟢 בדיקת Canva Education + הכנה

🟢 Design, Text, Elements, Shapes, Pages. 🟡 Canva AI / Create an Image לפי הרשאות. 🔄 בנייה ידנית ב־Elements.

לפני השיעור: פתח SKYLAND המתמשך ואת CHARACTER KIT; הכן STORY POSTER מוגמר + חלש; בדוק חשבון תלמיד; הכן fallback, טיימר, Boss ותבנית משוב.

🎬 WOW + Mission — תסריט

הצג את שני הפוסטרים. אמור: “יש לכם חמש שניות. מי הגיבור? מה הבעיה? מה הוא חייב לעשות?” לאחר מכן כתוב על המסך HERO → WANTS → PROBLEM → MISSION.

Mission: “לבנות STORY POSTER, לבדוק אם אדם אחר מבין את הסיפור, ולשפר לפחות דבר אחד לפני שמכריזים שהוא מוכן.”

🧭 הדרכה מעשית למדריך — בונים מול הכיתה

מטרת ההדגמה: המדריך בונה חלק אמיתי מהתוצר מול התלמידים. זהו scaffolding הוראתי שמיישם את עקרונות המפגש; אין צורך שהתלמידים יעתיקו את SKYLAND.

  1. פתחו את CHARACTER KIT ובחרו HERO.
  2. כתבו מול הכיתה HERO → WANTS → PROBLEM → MISSION.
  3. בחרו רגע אחד שמייצג את הבעיה/המשימה.
  4. פתחו עיצוב ב־Canva ובנו STORY POSTER: דמות, רגע חזותי, כותרת ומשפט Mission.
  5. טעות מכוונת: הוסיפו טקסט ארוך או כמה מוקדי תשומת לב. שאלו: “מה ראיתם ראשון?”
  6. הריצו 5-SECOND TEST, חזרו ל־Canva ותקנו דבר אחד.
  7. בסיום: STORY POSTER אמיתי שמוכן לשמירה ולמפגש 5.

🖥️ הדגמה צעד־אחר־צעד

  1. פתח SKYLAND ואת Cloud Leo מהמפגש הקודם.
  2. כתוב HERO: Cloud Leo.
  3. הוסף WANTS: לשמור על SKYLAND.
  4. הוסף PROBLEM: Crystal Gravity נעלם והאיים עלולים ליפול.
  5. נסח MISSION: למצוא אותו לפני הקריסה.
  6. בחר רגע אחד להצגה בפוסטר — לא את כל הסיפור.
  7. בנה שלד: גיבור, איום/בעיה, כותרת, משפט משימה.
  8. צור בכוונה בעיה בהיררכיה ושאל מה הצופה רואה קודם.
  9. שנה דבר אחד והראה Before → After. עצור לפני מוצר מושלם.

START → DECISION → TEST → CHANGE.

🛠️ תכנון → בנייה → בדיקה → שיפור

Plan: ארבעת רכיבי הסיפור לפני עיצוב. Build: משתמשים ב־CHARACTER KIT וב־WORLD KIT הקיימים. Check: היוצר שותק והבודק מספר מה הבין. Improve: שינוי אחד בעל השפעה גבוהה ובדיקה חוזרת.

CHANGE ONE THING AT A TIME.

🏆 אתגר בוס + גלריה

Boss — STORY IN 5 SECONDS: הצג את הפוסטר לחבר ל־5 שניות בלבד. הוא צריך לזהות HERO + PROBLEM + MISSION. אם לא — שפר היררכיה או מסר, לא קישוט.

Gallery: “אני מבין… / אני זוכר… / נתקעתי ב… / הייתי רוצה…”. אין דירוג יופי.

Super Boss: הסר רכיב אחד. אם הסיפור עדיין ברור, הסבר למה הוא Nice to Have ולא Must Have.

🛟 ערכת הצלה למדריך

אין סיפור? התחל: הגיבור רוצה ___ אבל ___ ולכן הוא חייב ___.
סיפור ענק? בחר בעיה אחת ומשימה אחת בלבד.
פוסטר עמוס? מה חייבים להבין ב־5 שניות?
AI חסום? 🔄 Elements + נכסים קיימים.
AI משנה דמות? השתמש בנכס הדמות הקיים; אל תיצור אותה מחדש.
מאחרים? קצץ קישוט, לא Test + Save + Next.
