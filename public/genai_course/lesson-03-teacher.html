🎯 מה באמת לומדים היום?

לבנות דמויות שונות בתפקיד אך עקביות עם העולם ועם CHARACTER DNA ברור.

המיומנות של היום: Character System Design

כלי החשיבה: WORLD DNA → CHARACTER DNA → ROLE → BUILD → TEST

איך מתרגלים? באמצעות התוצר הממשי של המפגש בתוך Canva — לא באמצעות Worksheet בלבד.

בסוף המפגש התלמיד יוכל: להראות את התוצר שבנה, להסביר החלטה מרכזית אחת ולתאר מה שיפר בעקבות בדיקה.

מה מלמדים היום?

התלמידים ממשיכים באותו פרויקט MY WORLD — [שם העולם] ומשתמשים ב־WORLD KIT ממפגש 2 כדי ליצור דמויות שנראות כאילו הן באמת שייכות לעולם. התוצר הוא CHARACTER KIT.

העיקרון המקורי של המפגש: CHARACTER DNA + HERO / FRIEND / RIVAL. המטרה אינה “לצייר שלוש דמויות יפות”, אלא ליצור מערכת דמויות עם זהות, תפקיד וקשר לעולם.

מדד: התלמיד מסוגל להסביר למה הדמויות שייכות לעולם, מה תפקיד כל דמות, ומה שופר בעקבות בדיקה.

🧑‍🏫 דוגמה מוכנה — SKYLAND

Cloud Leo — HERO: ממציא צעיר; Crystal Gravity מחבר אותו לעולם.

Zip — FRIEND: שותף מהיר וסקרן שעוזר לליאו לנוע ולגלות מקומות.

Rex — RIVAL: יריב שמאתגר את ליאו ויוצר מתח.

CHARACTER DNA משותף: פרטים כחול/לבן, מוטיבים של תעופה/שמיים, Crystal Gravity או סימן חזותי מקשר, ושפה שמתאימה ל־SKYLAND.

👎 דוגמה חלשה להשוואה

שלוש דמויות שאין ביניהן קשר חזותי, לא ברור מי HERO/FRIEND/RIVAL, ואחת מהן נראית כאילו הגיעה מעולם אחר. השאלה לכיתה: “מה חסר כדי שנאמין שהן חיות באותו עולם?”

🟢 בדיקת Canva Education + הכנה

🟢 Design, Text, Elements, Shapes, Pages. 🟡 Canva AI / Create an Image לפי הרשאות. 🔄 אם AI חסום — בונים דמות ידנית ב־Elements ושומרים על אותה מטרת למידה.

לפני השיעור: פתח את WORLD KIT של SKYLAND; הכן CHARACTER KIT מוגמר + גרסה חלשה; בדוק חשבון תלמיד; פתח תוצרי מפגש 2; הכן טיימר, Boss ומשוב קצר.

🎬 פתיחת WOW + המשימה — מה לומר

הצג את Cloud Leo, Zip ו־Rex, ואז גרסה חלשה. שאל: “בלי שמספרים לכם את הסיפור — מי נראה גיבור? מי חבר? מי יריב? ואיך אתם יודעים שהם מאותו עולם?”

כתוב: CHARACTER DNA + HERO / FRIEND / RIVAL.

Mission: “לבנות CHARACTER KIT, לבדוק אותו מול אדם או קריטריון, ולשפר לפחות דבר אחד לפני שמכריזים שהוא מוכן.”

🧭 הדרכה מעשית למדריך — בונים מול הכיתה

מטרת ההדגמה: המדריך בונה חלק אמיתי מהתוצר מול התלמידים. זהו scaffolding הוראתי שמיישם את עקרונות המפגש; אין צורך שהתלמידים יעתיקו את SKYLAND.

  1. פתחו WORLD KIT והצביעו על 2–3 מאפיינים שחייבים לעבור לדמויות.
  2. בנו CHARACTER DNA ל־HERO.
  3. צרו את HERO בפועל ב־Canva.
  4. בנו FRIEND ו־RIVAL: שנו תפקיד/צורה אך שמרו על קשר לעולם.
  5. טעות מכוונת: הציגו דמות יפה אך בסגנון זר. שאלו אם היא שייכת לעולם.
  6. בצעו ROLE TEST ללא הסבר ותקנו פרט אחד.
  7. בסיום: HERO + FRIEND + RIVAL מוצגים יחד כ־CHARACTER KIT.

🖥️ הדגמת המדריך — צעד אחר צעד

  1. פתח את נכסי SKYLAND: Cloud Leo + Zip + Rex ואת WORLD KIT.
  2. הראה את נקודת ההתחלה, לא רק תוצאה.
  3. כתוב CHARACTER DNA + HERO / FRIEND / RIVAL.
  4. התחל ב־HERO: תפקיד, אישיות, סימן חזותי וקשר לעולם.
  5. בנה שלד לפני צבע/אפקטים.
  6. הוסף פרט אחד והסבר למה הוא שם.
  7. בצע Preview/בדיקה.
  8. צור בכוונה בעיה — למשל דמות שלא מתאימה ל־WORLD DNA — ובקש לזהות.
  9. שנה דבר אחד בלבד והראה Before → After; עצור והעבר לתלמידים.

כלל: START → DECISION → TEST → CHANGE.

🛠️ תכנון → בנייה → בדיקה → שיפור

Plan: מנסחים מי הדמויות ומה תפקידן וכותבים CHARACTER DNA לפני יצירה.

Build: מתחילים בגרסה הקטנה; משתמשים ב־WORLD KIT במקום להמציא שפה חדשה.

Check: היוצר שותק. חבר צריך לזהות תפקיד וקשר לעולם.

Improve: בעיה אחת → שינוי אחד → אותה בדיקה שוב → רושמים למה.

CHANGE ONE THING AT A TIME.

🏆 אתגר בוס + גלריה

Boss: שנה פרט אחד בדמות בלי לשנות את התפקיד שלה ובלי לנתק אותה מהעולם. האם חבר עדיין מזהה HERO / FRIEND / RIVAL?

Gallery: בזוגות. “אני מבין… / אני זוכר… / נתקעתי ב… / הייתי רוצה…”. אין דירוג יופי; בודקים בהירות, זהות, סיפור ושיפור.

Super Boss: הסר רכיב שאינו חיוני. אם CHARACTER KIT עדיין עובד, הסבר מדוע הוא Nice to Have ולא Must Have.
