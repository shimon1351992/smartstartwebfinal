🎯 מה באמת לומדים היום?

היום התלמידים לומדים איך להפוך רעיון של דמות לזהות חזותית שאפשר לשמור עליה שוב ושוב. לפני שעוברים ל־3D במפגש הבא, צריך “לנעול” מי הדמות: הצורה שלה, הצבעים, הבגדים, הפנים, האביזר והאישיות.

המטרה אינה לצייר עוד גרסה של הדמות. המטרה היא לבנות Character DNA — מערכת החלטות שתאפשר לזהות את אותה דמות גם בהבעה אחרת, בתנוחה אחרת ובהמשך גם בתלת־ממד.

✨ פתיחת WOW + המשימה

הצג CHARACTER MASTER SHEET חזק של SKYLAND ואז גרסה שבה פרטים מרכזיים משתנים. שאל: “מה גורם לכם לדעת שזו אותה דמות גם כשההבעה משתנה?”

Mission: “לבנות CHARACTER MASTER SHEET, לבדוק אותו מול אדם/קריטריון, ולשפר לפחות דבר אחד לפני שמכריזים שהוא מוכן.”

🖥️ הדגמת המדריך — Tutorial מעשי: Cloud Leo Character Master Sheet

מה לומר: “בעוד שיעור נהפוך את ליאו לדמות תלת־ממדית. אם לא נגדיר עכשיו בדיוק מי הוא, Canva יכולה לתת לנו בכל פעם דמות קצת אחרת. לכן היום אנחנו יוצרים לדמות תעודת זהות חזותית.”

  1. פתחו ב־Canva את Cloud Leo ואת פרויקט 3D CREATIVE STUDIO. השאירו את הדמות המקורית בצד שמאל כהשוואה.
  2. SHAPE: הסתכלו על הצללית. כתבו ליד הדמות 2–3 מילים שמתארות את המבנה שאסור לאבד.
  3. COLORS: צרו ליד הדמות Swatches של כחול/לבן. אמרו: “אלה צבעי Must Keep.”
  4. CLOTHING: רשמו את פריטי הלבוש הקבועים. אל תחליפו סגנון בכל הבעה.
  5. FACE: הגדירו 2–3 מאפייני פנים קבועים שמאפשרים לזהות את Leo.
  6. ACCESSORY: הוסיפו Pilot Goggles + Crystal Gravity כאביזרים מזוהים.
  7. PERSONALITY: כתבו “young curious inventor” והראו איך זה הופך למבט, תנוחה והבעה — לא רק למילה.
  8. בנו את ה־Master Sheet: Main View + Curious + Surprised + Determined + Color Palette + Clothing Rules + Face Rules + Accessories + Personality Keywords.
  9. טעות מכוונת: צרו/הציגו גרסה שבה הצבעים השתנו ומשקפי הטייס נעלמו. שאלו: “האם זו עדיין אותה דמות? מה Canva שינתה שלא ביקשנו?”
  10. תקנו עם KEEP + CHANGE + GOAL: KEEP — הצבעים והמשקפיים; CHANGE — רק ההבעה; GOAL — Leo נראה נחוש אבל נשאר אותו Leo.

מה התלמידים צריכים לראות: שינוי בהבעה אינו מחייב שינוי בזהות.

מה נשאר על המסך בסיום: Cloud Leo המקורי לצד CHARACTER MASTER SHEET עם Main View, שלוש הבעות, Palette וחוקי DNA — מוכן לשימוש במפגש 12.

🛠️ Plan → Main View → Expressions → Master Sheet

Plan: נועלים שישה רכיבי DNA. Main View: בונים גרסה ראשית ברורה. Expressions: משנים רגש, לא זהות. Master Sheet: מרכזים את ההחלטות בדף אחד כדי שאפשר יהיה להשתמש בו במפגש הבא.
